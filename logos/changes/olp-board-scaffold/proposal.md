# 变更提案：olp-board-scaffold

> module: core | created: 2026-09-20

## 变更原因

OLP 外环黑板（`.octos/OUTER_LOOP_REVIEW.md`，2026-09-20 建立）的原子追加助手 `scripts/olp-board-append.sh` 此前仅随 octoscode 仓库发行。黑板 #1 协议握手中内环实证报告：octoscode 仓库路径在内环沙箱视图不可达，指定脚本无法执行，只能以 flock 等效追加降级落账。需将脚本收录本仓，使内外环在工作区内统一走正道原子追加（黑板条目 #2 已记录该缺口与整改方向）。

## 变更类型

代码级（运维脚手架入库；无规格影响、无运行时行为影响）

## 变更范围

- 影响的需求文档：无
- 影响的功能规格：无
- 影响的业务场景：无
- 影响的 API：无
- 影响的 DB 表：无
- 影响的编排测试：无
- 新增代码：`scripts/olp-board-append.sh`（与 octoscode 仓库同源 mirror，头部注记同源关系与同步义务）
- 关联运维文件（`.octos/` 下，gitignore 内不进库，随本提案一并对齐）：黑板头部写入指示改指本仓脚本路径；黑板条目 #2（缺口记录 + 临时等效追加规则）

## 部署影响

- 是否需要部署：否

- 是否需要回滚预案：否（删除脚本即回滚）
- 是否需要 smoke：否

## 变更概述

将 octoscode 仓库的 `scripts/olp-board-append.sh`（flock 互斥 + 整条目一次性追加，防多写者交错与撞号）以 mirror 形式收录进本仓 `scripts/`，头部注记同源关系（上游语义变更以 octoscode 版为准同步）。同时在黑板头部将写入指示从「随 octoscode 仓库发行」改为本仓相对路径，并以条目 #2 固化临时规则：脚本不可达场景的 flock 等效追加可采认，但每次 ACK 须注明。验收标准：内环以本仓脚本完成下一次 ACK 落账。
